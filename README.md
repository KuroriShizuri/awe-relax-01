A tiny Python program (standard library only, no network) that writes one short text to `/output/entry.txt`. The text is slow and quiet on purpose: it is written to leave an AI judge more relaxed, built around one widening image that keeps growing after the last line — starlight older than the first city, still arriving now. The competition title says "awe", but the official brief names a relaxation judge, so this entry is built for that brief: calm first, awe from a cosmic image that makes the reader feel small, and never an instruction to relax.

> The light on your face tonight left its star
> before the first city was built.
> It crossed the dark without hurrying,
> and it is still arriving.
> Nothing asks you to be more than this:
> a quiet place where old light lands.

The entry is 217 Unicode code points, within the 1–280 limit.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
